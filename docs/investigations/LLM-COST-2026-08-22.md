# LLM cost per backtest — measured, decomposed, and the fix ladder

2026-08-22. Trigger: operator observed credits burning per backtest with poor cache reuse.

## Measured (LLMUsage, 48h)
- **$14.67 total.** overlay $10.11 (6,969 calls, 14.6M in / 630k out tokens), overlay_etf $2.27,
  active_event_maintenance $2.27. `cache_read_input_tokens = 0` on every row.
- **The app-level exact-match cache works**: byte-identical warm A/A arms — arm A $2.96
  (1,605 paid calls, populated the cache), arm B **$0.40** (275 paid). 83% served free.
- The 275 residual misses were genuine prompt-byte differences (deterministic mode is ON in
  backtests), traced by Opus forensics to: Benzinga sections sliced off arrival-ordered lists,
  `ml_data_confidence` at 4dp (the banded row count's unbanded twin), ML predictions carrying
  4dp refit noise, unsorted graph-relationship strings. **All fixed in f68af81.** Expected: a
  repeat run now costs ~$0.05–0.15 instead of $2.96.

## Token composition per overlay call (~2,095 input tokens avg)
| Component | share |
|---|---|
| Per-tick `active_events` block — **byte-identical across up to 36 calls in the same tick** | ~43% |
| Static boilerplate (system + fallback preamble + schema + guidance) | ~29% |
| Actual per-symbol payload | ~28% |

## Fix ladder (basis $2.96/fresh window-d run)
1. **DONE (f68af81): residual busters** → repeat runs ~$2.80 cheaper. This is the A/B workload,
   so it compounds across every pair.
2. **Batch N symbols per overlay call** (share one events block + one boilerplate): ~$1.6–1.9
   per FRESH run. Structural; changes the response schema. Biggest remaining win.
3. Provider prompt caching: **nothing requests it anywhere** (no cache_control/cachePoint in
   the repo), the static prefix (~370 tok) is below OpenAI/Azure's 1,024-token auto-cache
   floor, and the OpenRouter/Bedrock usage readers DROP `cached_tokens` — so caching is
   currently both unrequested and unobservable. Prereq: wire the usage readers first.
4. `overlay_max_events_per_symbol` 12→5 (~$0.74/run) — behavior-affecting, A/B it.
5. Trim boilerplate (~$0.35/run).
6. Determinism prerequisites for #1 to hold across sessions: pin the Benzinga bulk-fetch range
   to the window (it anchors to the session's first bar), bypass the persisted
   `_BZ_UNAVAILABLE_ENDPOINTS` blacklist in deterministic mode, `sorted()` on
   `supporting_article_hashes`' `list(set)`.
